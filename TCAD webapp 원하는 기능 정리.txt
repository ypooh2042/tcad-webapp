TCAD webapp 원하는 기능 정리

- 프로젝트 폴더는 ~/TCAD 폴더 (SUPREM4GS 있는 폴더)로 함.
- 웹 상에서 SUPREM4GS 소스코드 작성이 가능.
- 작성한 SUPREM4GS 소스코드를 실행하면 서버사이드에서 SUPREM4GS 실행. .str plot 결과를 보여줄 수 있도록 함. postmini 기능들의 세련된 형태면 좋을 것 같음.
- examples 안에 있는 *.in 코드들 및 SUPREM4GS 폴더 안의 "Suprem-IV GS Manual.pdf"을 참고하여 사이트 내 docs 기능을 만들어 코드 작성에 참고가 되도록 하면 좋겠음.
- 이렇게 완성한 device를 테스트 하는 것은 DevSim 오픈소스 파이썬 툴을 활용하면 좋을 것 같음. 완전 오픈소스 반도체 시뮬레이션 툴로, 반도체의 전기적 특성 테스트에 최적화되어 있음. .str 결과를 통해 나온 시뮬레이션 결과를 활용해 DevSim device 시뮬레이션을 설계하고, 전기적 특성을 확인할 수 있도록 하는 웹 앱 기능이 있었으면 좋겠음. DevSim은 pip install devsim으로 설치 가능.
- DevSim 기능은 doc/devsim.pdf에 저장되어 있다 함. 참고하여 웹앱기능 작성.
- 사이트에 회원가입/로그인 기능이 있으면 좋겠음.
- 동시접속자 수를 10명으로 제한하는 기능이 있으면 좋겠음.
- 깃헙 연결을 하고자 함. "https://github.com/ypooh2042/tcad-webapp.git" 깃 레포지토리 주소임. 일단은 private으로 해두었지만 public으로 바꿀 예정. 보안 상 민감한 정보들은 .gitignore에 반영하여 업로드되지 않도록 주의.
- 사이트는 일단 www.ypooh2062.link에 포트 연결해 nginx로 열어주면 될듯함. https 연결 고려하여 작성하도록.

기타 고려할 만한 추가 기능이나 질문사항이 있다면 작업 전에 꼭 말해 주길 바람.
