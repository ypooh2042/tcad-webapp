# 검토 중인 패치 (빌드에 들어가지 않음)

`docker/suprem/Containerfile` 은 `patches/` 만 적용한다. 이 디렉토리는
**동작은 확인했지만 대가가 커서 채택을 보류한** 수정을 둔다.

## 0008-deposit-fresh-material-undoped.patch

갓 증착된 재료에 도핑이 들어가는 문제를 고친다.

새 영역을 삼각화하며 생기는 점은 `alloc_nd` 가 1e5 로 초기화하지만, 뒤이은
세분화가 **같은 물질인 이웃 영역의 경계값에서 보간**해 채운다. 그래서 도핑된
산화막 위에 산화막을 증착하면 아래층 도펀트가 새 층으로 번진다.

**상류 원본의 동작이다.** 구버전 바이너리(`pre-elem-etch`)로 같은 구조에
증착해 확인했다 — 요소 기반 식각과 무관하다.

| 같은 구조에 `deposit oxide thick=1.0` | 새 영역 내부 노드 중 도핑된 것 |
|---|---|
| 구버전 B-rep | 3084 / 4039 (최대 6.8e20) |
| 현재 배포본 | 2387 / 3252 (최대 6.6e20) |
| 이 패치 | **0 / 3252** (전부 1e5) |

계면 노드 262 개는 그대로 둔다. 같은 물질 계면에서는 노드가 하나뿐이라
지우면 아래층이 원래 갖고 있던 도펀트까지 잃는다.

### 보류하는 이유

도핑은 적응 격자를 좌우한다. 증착층을 1e20 에서 1e5 로 되돌리면 계면에
가파른 기울기가 생겨 격자가 달라지고, 그 여파로:

- 52/53 단계 CMOS 흐름이 step 34 에서 `error in chop` 으로 죽는다.
- 번들 예제 13 개 중 4 개(exam1, exam2, exam4, mosfet)의 결과가 바뀐다.
  (죽는 예제는 없다.)

점결함(I, V)과 산화종(O2, H2O)까지 되돌리면 훨씬 일찍 죽는다(질화막 증착 뒤
습식 산화에서 사망). 그래서 화학 도펀트만 되돌리도록 좁힌 상태다.

채택하려면 증착 계면의 격자 대응을 함께 손봐야 한다.
